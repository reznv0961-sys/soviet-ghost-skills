# Canon 规则

## 状态值

- `CANON`：用户已明确确认；未经询问不得更改。
- `PROVISIONAL`：仅供讨论的候选内容，不得当成既定世界事实。
- `RESEARCH_REQUIRED`：依赖尚未解决的真实历史；确认前不得写入正式剧情或 canon。

所有主张都应在 `historicalResearch` 中可追溯。状态变化时保留原有编号，并说明如何解决，不得静默替换。

## 优先级

1. 用户确认的 canon
2. 用户确认的 payoff
3. 历史准确性
4. 调性一致性
5. 人物逻辑
6. 叙事回报
7. 制作可行性
8. 通用短剧节奏惯例

如果平台惯例与本系列核心调性冲突，优先保护作品调性。

## 必须取得用户确认的事项

新增、删除、移动 payoff，改变其 level 或 type，或改变其核心含义之前，必须暂停并询问用户。依赖未经确认的真实历史时也必须暂停。格式整理、ID 统一、JSON 修复、报告渲染、资产汇总，以及对已确认内容的措辞润色，可以直接进行，不必重新打开已拍板的决定。
