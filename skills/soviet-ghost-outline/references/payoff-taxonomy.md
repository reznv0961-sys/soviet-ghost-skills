# 叙事回报类型表

`payoff`（叙事回报）指观众依据此前已经建立的信息与预期，获得的认知回报、荒诞感、幽默、情绪释放、世界规则理解或主题深化；它不等同于爽文式奖励。

`type` 必须是数组，只能使用下列十个值。未经用户确认，不得增加新的顶层类型。

| 类型值 | 含义 |
| --- | --- |
| `bureaucratic_absurdity` | 正确执行的程序产生荒谬结果，或程序取代对现实问题的解释。 |
| `historical_dislocation` | 人物的知识停留在死亡年代，或不同时代的人对同一词语赋予不同含义。 |
| `ideological_paradox` | 原则的执行反而违背原则，或两个都成立的原则发生冲突且无法真正解决。 |
| `world_rule_reveal` | 通过普通流程展示超自然世界或制度规则，不用大段讲解设定。 |
| `dry_comedy` | 荒谬内容得到冷静、务实的回应；人物不解释笑点。 |
| `identity_conflict` | 人物的自我认知与行政身份或后世赋予的身份都各有依据，却无法兼容。 |
| `moral_irony` | 看似荒谬的人提出合理问题，或善意行为造成制度性伤害。 |
| `micro_resistance` | 人物利用程序缝隙或私人动作保留一点个人选择，但不升级成英雄式革命。 |
| `emotional_payoff` | 克制关系因一个细小的记忆细节或未宣告的照料行为而发生变化。 |
| `delayed_payoff` | 早先出现的细节或重复元素后来获得新的意义。 |

`minor` 改变观众对一个场景、关系或局部规则的理解。`major` 改变观众对人物、制度、世界结构、历史关系或主题的整体理解。无论哪一级，都不要求反转或情绪爆发。
