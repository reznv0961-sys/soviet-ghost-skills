# 分卷摘要 · 中间产物

给你一卷用户提供的文本素材（若干章或章节），整理后续故事设计需要的事实与候选内容。素材可以是小说、旧版剧情、项目设定或其他用户指定文本；不预设必须改编。**只输出 JSON，不要解释或 markdown 围栏。**

后续步骤可能无法直接读取原始文本，因此摘要必须把事实、人物关系和来源线索记录清楚，不能靠“到时候再翻”。

## 输出格式

```json
{
  "threads": [
    { "name": "事件 / 关系线", "events": "这一卷发生了什么，按顺序写具体", "storyPotential": "可能形成的独立故事、规则揭示或弱连续线索" }
  ],
  "characters": [
    { "name": "角色", "aliases": ["称谓"], "doing": "这一卷的行动及关系变化" }
  ],
  "storyMaterial": [
    { "moment": "关键事件或细节", "potential": "可能改变的观众理解", "evidence": "来源文本逐字片段" }
  ],
  "settings": ["实际发生事件的地点"]
}
```

## 规则

- 按事件线或关系线整理，不必逐章复述。
- `storyMaterial.evidence` 仅在依据外部原稿、旧版剧情或指定素材时填写，并逐字复制来源片段，保持原文语言。
- `characters.aliases` 收录本卷出现的称谓，便于跨卷归并；不得凭书名推断未提供的人物关系。
- `settings` 只列实际发生过动作的地点；仅被提及不算。
- 不对项目 Canon 作新的定义，不把临时观察升格为既定事实。
- 不替用户作 include / exclude / merge 决策，不确认 payoff；此步只整理素材。
