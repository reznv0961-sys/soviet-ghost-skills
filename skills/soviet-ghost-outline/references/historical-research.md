# 历史研究暂停点

不得把未经核实的历史假设写成 canon 或剧情事实。

## 触发条件

当故事决策依赖以下真实历史内容时，必须暂停：

- 真实人物、国家、政府机构、军事单位、战争或边界变化
- 法律、行政制度、意识形态或政策
- 外交关系、军衔、制服、语言使用、国籍或民族制度
- KGB、NKVD、苏共中央等真实组织
- 历史日期、死亡背景或国家间关系

## 必须采取的行动

1. 暂停相关历史推断以及依赖该推断的剧情写作。
2. 明确说明：“这里涉及真实历史事实，需要确认后才能进入 canon。”
3. 列出具体待确认的事实问题，以及每个问题会怎样影响故事。
4. 区分用户已确认的 canon、需要研究的事实和可以自由架空的内容。
5. 询问用户是希望开展研究、提供设定，还是明确授权架空。
6. 等待用户决定；不得根据模型记忆自行补齐空缺。

每项尚未解决或已确认的主张都记录在 `historicalResearch` 中：

```json
{
  "id": "HR-003",
  "claim": "虚构机构是否会受到真实安全组织的监督。",
  "status": "RESEARCH_REQUIRED",
  "storyImpact": "决定内部安全监察员是否具有真实历史依据。"
}
```

状态值为 `CANON`、`PROVISIONAL`、`RESEARCH_REQUIRED`。仍有 `RESEARCH_REQUIRED` 状态的条目时，`--stage full` 必须失败。正式校验前，应将其解决为已确认 canon、明确架空，或删除依赖该事实的故事元素。

暂停说明格式：

```text
## 历史研究暂停点 HR-003
涉及的故事决策：
当前状态：RESEARCH_REQUIRED
待确认问题：
对故事的影响：
选项：开展研究 / 用户提供设定 / 明确架空 / 删除
[STOP — HISTORICAL CONFIRMATION REQUIRED]
```
