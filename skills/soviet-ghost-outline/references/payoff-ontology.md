# 叙事回报因果结构

Ontology（本体结构）描述一项叙事回报成立所需的因果形状，不是固定剧情模板。`payoffs[].ontology` 使用对应的标识，例如 `bureaucratic_absurdity_A`。

## `bureaucratic_absurdity`（官僚荒诞）

- **A——规则被正确执行，却导向荒谬结果：**正式规则 → 工作人员严格执行 → 个案与规则发生结构性冲突 → 没有人质疑规则本身 → 荒谬结果被当作普通行政结果接受。
- **B——程序取代现实原因：**人物提出现实问题 → 官员不给实质解释 → 引用表格、条例、编号或流程 → 程序本身被当作答案。

## `historical_dislocation`（历史错位）

- **A——知识停留在死亡年代：**人物在 T1 死亡 → T2 发生重大历史变化 → 人物在 T3 被要求理解或选择变化后的现实 → 信息差造成困境或荒诞。
- **B——不同时代共处一个空间：**受不同时代影响的人使用同一个词 → 各自理解不同 → 这种错位改变场景含义。

## `ideological_paradox`（意识形态悖论）

- **A——原则的执行产生原则的反面：**制度宣称原则 X → 建立机制 Y 来落实 X → Y 反而强化了 X 原本试图消除的分类。
- **B——有效原则彼此冲突：**原则 A 与原则 B 都成立 → 个案同时触发两者 → 系统没有真正解法 → 临时程序掩盖矛盾。

## `world_rule_reveal`（世界规则揭示）

- **A——通过日常流程展示规则：**观众尚不知道某项规则 → 人物进入普通流程 → 工作人员按惯例处理 → 观众自然推知规则，不进行设定倾倒。
- **B——旧事件获得新解释：**先发生一个未解释的现象 → 后续流程揭示其制度原因 → 观众重新理解前面的场景。

## `dry_comedy`（冷幽默）

- **A——荒谬事实配正常语气：**极端事实 → 人物反应克制 → 用普通行政或生活语言回应 → 幽默来自内容与语气的反差。
- **B——严肃铺垫得到微小行政答复：**观众预期重大解释 → 官员认真查阅记录 → 答案却极其琐碎、技术化或程序化。人物不得主动说这很好笑。

## `identity_conflict`（身份冲突）

- **A——自我身份与系统身份不一致：**人物认为自己是 X → 系统只能将其归为 Y → 两者都有理由 → 无法通过简单判定对错解决。
- **B——身份被历史重新命名：**人物死亡时的身份是 A → 后来的政治秩序定义了 B → 系统要求人物接受 B。

## `moral_irony`（道德反讽）

- **A——不被看好的人提出合理问题：**观众先否定某个人或机构 → 更深层矛盾浮现 → 该人物提出简单合理的问题 → 暴露另一处制度盲点。
- **B——善意行为造成制度伤害：**人物出于善意帮助他人 → 制度结构改变行为后果 → 实际结果与初衷相反。

## `micro_resistance`（微小反抗）

- **A——不违反制度，但改变执行方式：**人物无法取消规则 → 利用程序缝隙 → 给他人留出有限空间。
- **B——形式服从，保留个人判断：**公开行为符合制度 → 私下的小动作保留另一种立场。

不得自动把这些结构升级成演讲、暴力反抗或英雄式挑战体制。

## `emotional_payoff`（情绪回报）

- **A——长期克制后出现微小人性瞬间：**人物一直维持职业或防御状态 → 某个细节触及私人记忆 → 只出现轻微情绪变化 → 不加解释。
- **B——关系通过行动改变：**人物彼此保持距离 → 一方做出不起眼的帮助 → 另一方察觉 → 关系发生轻微变化。

## `delayed_payoff`（延迟兑现）

- **A——早期细节后来获得意义：**早期出现一个暂未解释的细节 → 后续信息出现 → 细节的真实作用显现。
- **B——重复元素的含义逐次变化：**物件、规则或句子反复出现 → 每次上下文改变 → 最后一次出现深化主题。
